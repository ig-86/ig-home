# İsmet Home

Home Assistant için tam ekran pano ve yönetim paneli. Entegrasyon: `ismet_home`, pano stratejisi: `custom:ismet-home`.

```
strategy:
  type: custom:ismet-home
```

**Based on Lemur Home Dashboard by mendeburlemur — https://github.com/mendebur-lemur/lemur-home-dashboard**
